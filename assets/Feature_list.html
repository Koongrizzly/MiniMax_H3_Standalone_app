1. Generation

Main MiniMax H3 Generator

Text to Video (T2VA) — Generate complete MiniMax H3 video and audio directly from a text prompt.

Latent Continuation — Continue from saved native MiniMax H3 video/audio latents instead of rebuilding history only from decoded frames.
Frames + Latent Continuation — Combine decoded-frame memory with native latent memory for stronger continuation consistency.
Automatic latent fallback — Falls back to normal frame-based continuation when a compatible saved latent is unavailable.
Exact final-frame boundary — Continuation can preserve the precise visual boundary between the old clip and new generation.
Audio Memory Continuation — Carry the final 1 second of source audio into the next generation as H3 audio history.
Timeline-aligned sound memory — Audio continuation is aligned to H3's native 40 Hz audio timeline.
Glue Results — Automatically join continued results into a longer combined video.
Reference to Video (Ref2VA) — Generate video using image video and audio references.
Up to 9 image references — Supply as many as nine visual <Picture> references to a Ref2VA generation.
Up to 3 video references — Video references can be supplied with their soundtrack extracted when available.

Native reference ordering — Automatically preserves H3's <Picture> <Audio> and <Video> reference ordering.
Reference image sizing — Choose matching reference size or maximum-size reference processing.
Exact source audio mode — Lock Audio 1 into the target audio latent and use the original untouched audio in the final output.
Prompt-controlled native audio — MiniMax can generate dialogue sound effects ambience music and other audio from the same video prompt.

21:9 generation — Dedicated ultrawide output with separate widescreen quality presets.
MiniMax-safe resolution mapping — Displayed formats automatically resolve to valid H3 tensor dimensions such as 1280×704.
Variable duration/frame presets — Select H3-compatible frame counts at 24 FPS.
Experimental long-duration mode — Unlock longer generation lengths beyond the normal frame selection.
24 FPS workflow — Generation duration and frame calculations consistently use 24 frames per second.
Seed control — Use a fixed reproducible seed or -1 for a fresh random seed.
Steps control — Manually choose the number of diffusion sampling steps.
Up to 3 LoRAs — Stack as many as three MiniMax H3 diffusion-model LoRA adapters.
Independent LoRA strengths — Every LoRA has its own strength including zero and negative compatible values.
CFG control — Direct control over classifier-free guidance.

Timeline block colors

Green #2f6b4f — Finished — The block has successfully generated output.
Blue #236b84 — Running — MiniMax is currently generating that timeline clip.
Grey #5c6470 — Pending — The block has been queued and is waiting to run.
Red #783c3c — Failed — Generation for the block ended in an error.
Muted red/brown #6b5353 — Cancelled — Generation was manually or externally cancelled.
Orange/brown #806528 — Stale — Existing output remains usable but timeline continuity/settings changed after it was rendered.
Default dark/grey panel — Draft — The block has not yet been rendered or queued.
Highlight border — Selected — Selected blocks use the current UI highlight color with a thicker border.
Yellow LOCK — Locked — A protected block shows a yellow lock indicator and cannot be accidentally regenerated or structurally edited.

Timeline block labels and badges

HQ — The actual rendered video is 704 pixels high or higher regardless of how it was generated.
L — The active rendered clip used latent continuation memory.
F — The clip used frame-based visual conditioning or continuation memory.
A — The clip used audio input or audio continuation memory.
Ref — The clip was generated with Ref2VA image references.
⚠ — A required continuation/start-video dependency is missing or broken.
LOCK — The timeline block is protected against destructive generation/editing operations.
◆ New — The block starts a new generation rather than continuing the previous video.
↪ Continue — The block continues directly from the previous timeline clip.
▣ Loaded start clip — The block represents an existing video loaded as the start of the chain.
⇥ Next frame — The generation uses the first frame of the following clip as an ending anchor.
Ref2VA ×N — Shows how many reference images are active for that timeline clip.
###f — Displays the exact MiniMax frame count assigned to the block.
#.##s — Displays the resulting clip duration in seconds.
